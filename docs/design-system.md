# SkinSabi design system

## Illustrations

SkinSabi draws no people, faces, or characters. Artwork uses objects, product scenes, and non-human abstract shapes. Skin-tone swatches are display-only color samples with labels in HTML.

The supplied object illustrations are inline SVGs. Their frame color comes from `--illus-frame`, with a theme-specific value for light and dark themes. Motion hooks are reserved for a future motion pass; these illustrations remain in their resting state by default.
